# Система прогнозирования турнирных игр по CS2

## Описание

Система предназначена для прогнозирования исходов матчей CS2 на основе данных о картах, командах и игроках.  
Пользователь взаимодействует через Telegram-бота, который отправляет запросы на сервер API.  
API сервер создаёт задачи прогнозирования, которые обрабатываются Celery воркерами с использованием обученной ML модели.  

Система также включает фоновую обработку данных и обучение модели:

- **Обновление словарей** (`maps`, `teams`, `players`) из сырых данных матчей.
- **Загрузка словарей** в базу данных.
- **Обучение ML модели** на исторических данных матчей.
- **Инференс прогноза** для новых матчей.

## Пользовательский сценарий

1. **Регистрация и авторизация через Telegram бот**
    - Пользователь создаёт аккаунт в системе.
    - Бот выполняет авторизацию пользователя, запрашивая логин и пароль.
    - Бот получает JWT-токен для доступа к API и сохраняет его для дальнейших запросов.

2. **Взаимодействие через Telegram бот**
    - Пользователь выбирает карту, команды и игроков для матча.
    - Бот отправляет данные на API для создания задачи прогнозирования, используя токен для аутентификации.

3. **Создание задачи прогнозирования**
    - API сервер принимает данные, проверяет их корректность и создаёт задачу в Celery.
    - API возвращает идентификатор задачи (`task_id`) для отслеживания.

4. **Обработка задачи Celery Worker**
    - Воркер получает задачу из брокера сообщений.
    - Загружает ML модель, формирует признаки и делает прогноз.
    - Сохраняет результат выполнения задачи.

5. **Получение результата**
    - Telegram бот периодически проверяет статус задачи через API, используя токен.
    - Получает прогноз исхода матча или статус обработки (PENDING/ERROR).
    - Отправляет прогноз пользователю.

6. **Фоновые задачи**
    - Обновление и загрузка словарей карт, команд и игроков.
    - Обучение ML модели на исторических данных.
    - Сохранение метрик модели и ML pipeline.

## Использованные технологии

- **Python 3.11+**
- **Django 5** – REST API, модели, аутентификация
- **Django REST Framework** – создание API endpoints
- **drf-spectacular** – автогенерация OpenAPI схемы и Swagger UI
- **djangorestframework-simplejwt** – JWT авторизация
- **Celery + Redis** – обработка фоновых задач
- **django-celery-beat** – периодические задачи
- **PostgreSQL** – реляционная база данных для словарей и истории матчей
- **NumPy, SciPy, scikit-learn, joblib** – ML модель и вычисления
- **Python-dotenv** – конфигурация через `.env` файлы
- **Telegram Bot (aiogram / httpx / aiohttp)** – взаимодействие с пользователем
- **Poetry** – управление зависимостями и виртуальным окружением
- **Pytest / pytest-django / pytest-asyncio / testcontainers** – тестирование
